# Financial Market Risk & Return Analysis

This project applies data science techniques to real-world financial data to analyse asset performance, volatility, correlations, and risk-adjusted returns.

## Overview

The analysis uses Python and real market data (via yfinance) to explore:

- price performance across major tech stocks and the S&P 500
- daily returns and volatility
- correlation between assets
- drawdown analysis
- Sharpe ratio comparison
- portfolio performance

## Technologies used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance

## Key insights

- NVIDIA shows exceptional growth driven by AI demand
- High-growth stocks exhibit significantly higher volatility
- Tech stocks are highly correlated, reducing diversification
- Risk-adjusted metrics provide a more balanced comparison than raw returns
- Portfolio diversification improves stability
